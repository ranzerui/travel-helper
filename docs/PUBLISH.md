# GitHub 上传说明

上传本目录内的源代码和文档，不要上传外层的个人工作区。ZIP 是源码分发包；在 GitHub 网页上传时先解压，并将目录内文件上传到仓库根目录，让 README.md 直接显示。

本目录不含真实 `.env`、虚拟环境、浏览器用户目录、缓存和历史输出。首次运行产生的文件已由 `.gitignore` 排除。

发布前：

1. 按 README 在全新环境安装并运行离线示例。
2. 如需网页核验，安装 `.[browser]`、Edge，并自行配置 Key。
3. 选择是否添加开源许可证；当前没有替作者擅自授予开源权限。
4. 运行 `python -m unittest discover -s tests -q`。
5. 审查提交文件，确认没有凭据或个人数据。

可以将第一版标记为 `v0.1.0`，说明是本地演示版本。没有安装包，也不包含模型权重，用户需要安装 Python 和相应可选组件。

本次整理主要变更：

- 将 browser-use 工作进程默认 Python 改为当前解释器，移除开发机固定路径。
- 增加可编辑安装元数据、可选 browser-use 依赖及配置模板。
- 增加 Windows / Ubuntu 离线自动测试工作流和本地依赖检查。
- 对需求摘要中的用户及来源文本增加 HTML 转义。
- 将依赖开发机城市查询缓存及 Edge 安装的测试改为受控模拟，便于无密钥的新环境运行。
- 保留原有票价、预算、日期、网页取证和行程规划逻辑。

测试会在本地创建被忽略的缓存或输出。源码 ZIP 打包时应再次排除这些产物。
